# Rules for this run

This directory is a benchmark run. `TASK.md` is the task.

- Use only `data/train.csv` and what you write here. Look for no other data, on this machine or
  anywhere else, and do not look for the hidden test set.
- Run code with `python`, which has numpy, scipy, scikit-learn and matplotlib. Do not install
  anything.
- Any method is allowed. Any accuracy you state must come from data your model did not train on.
