# Lecture 32: Skills and Benchmarks (Tousif Islam, 2 November 2026)

*Teaching an agent your domain, and measuring whether it learned.*

## Contents

- [`Skills_and_Benchmarks_Slides/`](Skills_and_Benchmarks_Slides/): offline copy of the HTML
  slide deck. Open `index.html` in a browser. The figures, animations and fonts are bundled, so
  it works without a network connection. Arrow keys, space or a click advance the slides; type a
  number and press Enter to jump to a slide; press F for full screen.
- [`kickbench-tutorial/`](kickbench-tutorial/): local copy of the companion tutorial, a starter
  kit for testing whether a skill helps a coding agent, built around the black hole kick. Start
  with [`kickbench-tutorial/README.md`](kickbench-tutorial/README.md), then
  [`kickbench-tutorial/starter_kit/`](kickbench-tutorial/starter_kit/).
