# Multi-Agent Systems for Science — lecture notebooks

Notebooks of the lectures of *Multi-Agent Systems for Science* (Boris Bolliet,
University of Cambridge). Course site: <https://teaching.borisbolliet.io/mas-2026/>

Each lecture's notebook is added here when the lecture is released, under
`classNN/`, with the `requirements.txt` of the versions it was run with. Every
notebook opens in Google Colab from its lecture page. The notebooks call a
language model (Gemini by default, one line to change provider) and run the
Python code that the model writes; Colab or a container is the safe place to
run them.
